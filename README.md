# Словасьянс / Worditaire — MVP

Откройте `index.html` напрямую или через локальный HTTP-сервер.

## Контент

- `data/categories.json` — основная редактируемая база категорий (148 категорий, по 10–11 слов).
- `data/categories.js` — резервная копия той же базы для запуска через `file://`, где браузер может запретить `fetch()` JSON.
- При размещении на обычном хостинге игра сначала загружает `categories.json`.

## Защита от повторов и неоднозначности

При генерации раунда игра:

1. исключает последние 40 использованных категорий, пока это возможно;
2. не берёт две категории из одной `conflictGroup`;
3. учитывает явный массив `conflicts`;
4. автоматически запрещает совместное появление категорий, если в их полном словаре есть одинаковые слова;
5. только после подбора совместимых категорий выбирает по 3–9 слов каждой категории.

Например, `Небо` и `Космос` входят в одну конфликт-группу `astronomy`, поэтому никогда не появляются в одном раунде. Дополнительно слово `Метеор` встречается в обеих категориях и само по себе также создаёт конфликт.


## UX/UI

- mobile-first интерфейс с фиксированным размером карт;
- яркие, но различимые визуальные уровни: фон → игровое поле → карты → интерактивные элементы;
- прогресс категорий всегда виден в верхней панели;
- короткая одноразовая подсказка для первого запуска;
- микроанимации, haptic feedback (если браузер поддерживает) и визуальная награда за завершение категории;
- отдельный праздничный экран завершения уровня;
- поддержка `prefers-reduced-motion`.
