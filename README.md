# Ассоциации — Косынка MVP

Откройте `index.html` в современном браузере.

Реализовано:

- 3–6 случайных колонок;
- первая строка: закрытая колода и сброс;
- вторая строка: столько компактных слотов категорий, сколько колонок;
- третья строка: неравномерно заполненный расклад;
- примерно половина всех карт раунда раздаётся в расклад, остальные остаются в колоде;
- закрытые и открытые карты видны каскадом;
- объединённые слова остаются видимыми отдельными слоями;
- карточки категорий переносятся в верхние слоты;
- группы карт переносятся целиком мышью или пальцем;
- при перетаскивании целевые зоны не подсвечиваются.
