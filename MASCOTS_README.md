# Интеграция первых новых маскотов

> Историческая implementation note. Не является источником character canon.  
> Текущий канон: `docs/design/CHARACTER_WORLD_MANIFEST_v0.15.md`.

## Что подключено
- Лис — 5 WebP-форм.
- Мудрая сова — 3 WebP-формы.
- Кот-учёный — 3 WebP-формы.

## Визуальные стадии исторической интеграции
Лис: уровни 1–5 → формы 1–5.

Сова и Кот: уровни 1–2 → форма 1; 3–4 → форма 2; уровень 5 → форма 3.

`evolutionStage` этой исторической интеграцией не переопределялся: визуальная форма выбиралась по `level` маскота.

Для Лиса, ещё не ставшего спутником, в прежней реализации финала главы использовалась его последняя форма как сюжетный образ. Это не является актуальным narrative canon Мира Леса.

## Важно
Проект хранит `level`, `progressXp` и `evolutionStage`, но эта note не определяет полноценную механику развития. Нормативная progression-модель проектируется отдельно.
