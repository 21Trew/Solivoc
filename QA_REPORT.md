# QA report — Словасьянс v14

Проверки выполнены перед сборкой этого архива.

## Автоматические проверки

- `node --check` для всех JS/MJS и service worker — пройдено.
- JSON parse: `manifest.webmanifest`, `package.json`, `vercel.json`, `data/categories.json` — пройдено.
- В `index.html` нет повторяющихся `id`; все локальные `<script>` / `<link>` существуют.
- Словесная база после sanitization: 148 категорий; названия с пробелами больше не отбрасываются.
- Визуальная база: 150 категорий, 25 тематических наборов; внутри категорий нет точных дублей emoji.
- Визуальные названия проверены: повторяющихся названий внутри базы картинок нет.
- Генератор: 80 последовательных обычных уровней в смешанном режиме — 0 дублей названий внутри уровня и 0 повторов категории на соседнем уровне.
- В тестовой серии минимальный интервал повторного появления одного названия составил 7 уровней.
- Runtime больше не меняет ширину карточек при вертикальной подгонке: сжимаются только высота и шаг каскада.

## Изменения этого прохода

- усилен cooldown недавних категорий и блокировка одинаковых названий в одном раскладе;
- восстановлены естественные названия категорий с пробелами;
- пересмотрены визуально похожие emoji, в том числе «Земля», «Луна» и эмоции;
- увеличены карточки в 4/5 колонок и сделана плавная вертикальная подгонка;
- новая победная анимация: круглая награда, конфетти и отдельная победная музыка;
- отдельная фоновая музыка для вызова друга;
- награды за повышение ранга: новые аватары, титулы и rank-up modal;
- профиль вынесен в постоянный верхний header игры и всех вкладок hub;
- добавлено удаление/отмена вызова, включая удаление активного server-side challenge;
- добавлена настройка старта: «Стартовая» / «Сразу в игру»;
- PWA cache обновлён до `worditaire-v23`.

## Ограничение среды проверки

Headless Chromium в текущем окружении зависает из-за системных/DBus ограничений, поэтому полноценный визуальный runtime-smoke здесь не завершён. Статические, генераторные и синтаксические проверки пройдены; после Vercel deploy стоит коротко проверить визуально 3/4/5 колонок, rank-up и отмену вызова на реальном устройстве.
