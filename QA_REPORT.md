# QA report — Словасьянс v8

Проверки выполнены перед сборкой этого архива.

## Автоматические проверки

- `node --check` для всех `js/*.js`, `js/**/*.js` и `api/*.mjs` — пройдено.
- JSON parse: `manifest.webmanifest`, `package.json`, `vercel.json`, `data/categories.json` — пройдено.
- В `index.html` нет повторяющихся `id`; все локальные `<script>` / `<link>` существуют.
- Все ресурсы из `sw.js -> CORE` существуют.
- Словесная база после sanitization: 135 категорий.
- Визуальная база: 150 категорий, 150 уникальных ID, 25 тематических наборов.
- Seed stress-test: по 30 обычных уровней для режимов `words`, `pictures`, `all` — 90/90 сгенерированы.
- Отдельный генератор коллекций: 25/25 визуальных наборов сгенерированы.

## Проверенные зоны по коду

- onboarding первого запуска и переход во встроенное обучение;
- недельный recap и миграция профиля;
- адаптивная сложность только обычной кампании (Daily / challenge / финалы не персонализируются);
- энциклопедия: поиск, фильтры, сортировка, слова / картинки;
- история дуэлей и быстрый реванш;
- профиль: любимая категория и до 3 избранных достижений;
- события первого открытия, onboarding, tutorial, уровней 1/2/5, D1/D7 и challenge funnel;
- `/api/analytics`: анонимная запись + защищённое чтение по `ANALYTICS_ADMIN_TOKEN`;
- PWA cache обновлён до `worditaire-v17`.

## Ограничение среды проверки

Headless Chromium в текущем окружении блокирует `127.0.0.1` корпоративной политикой (`Your organization doesn’t allow you to view this site`), поэтому полноценный визуальный runtime-smoke в браузере здесь выполнить нельзя. Перед production-релизом рекомендуется коротко пройти основные сценарии на реальном телефоне после Vercel deploy.
